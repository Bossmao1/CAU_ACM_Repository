## 题目描述

甲，乙两个人玩 Nim 取石子游戏。

Nim 游戏的规则是这样的：地上有 *n* 堆石子，每人每次可从任意一堆石子里取出任意多枚石子扔掉，可以取完，不能不取。每次只能从一堆里取。最后没石子可取的人就输了。假如甲是先手，且告诉你这 *n* 堆石子的数量，他想知道是否存在先手必胜的策略。

## Part 1 位运算

位运算的作用千千万， 此处我们做出简单介绍。

在程序设计之中， 位运算是定义在非负整数之上的运算 。 （扩充定义域的情况本人不了解）

在所有之前， 我们要知道， 所有十进制的数都唯一对应一种二进制表示

例如 $5$ 所对应的二进制表示 为  $101_2$ ， $11$ 对应的二进制表示为 $1011_2$

在这种表示下， 我们称从右往左的第1个数为第1位， 第2个数位第2位 以此类推。

如， $5$ 在二进制表示下的第1位 为1， 在二进制表示下的第2位为0,  在二进制表示的第4位为0 

对于一个二进制数， 我们记 第 $i$ 位为 $a_{i}$ （$a_i$ 只可能是 0 或者 1， 我们称这样取值只能是0 或者 1 的变量为布尔变量(bool)）

则其与对应的十进制数 $x$ 有着如下关系

$x = \sum\limits_{i = 1} a_i·2^{i -1}$

#### 与

在文本之中 该符号写作 $\wedge$ , 在代码之中 该符号写作 $\&$

倘若我们要将 $a$ 和 $b$ 作与运算我们这么写

```c++
a & b
```

运算定义： 

​	记 $a_i$ 为 $a$ 在二进制下的第 $i$ 位， $b_i$ 为 $b$ 在二进制下的第 $i$ 位

​	我们有

​	$a \wedge b = \sum\limits_{i = 1} (a_i \wedge b_i) ·  2^{i - 1}$

​	其中 $a_i$ 与 $b_i$ 均为 bool 变量 

​	对于两个布尔变量 $A$ 和 $B$：
$$
A \wedge B = 
\begin{cases} 
1 & \text{如果 } A = 1 \text{ 且 } B = 1 \\[2mm]
0 & \text{否则}
\end{cases}
$$
小例子 ：

​	$4 \wedge 3 = 0, 11 \wedge 5 = 1, 7\wedge3 = 3$

根据与运算的定义我们有如下trick， 我们判断一个数是否为偶数有这样一种装 B 的写法

```c
if (x & 1)
	printf("%d是奇数", x);
else 
	printf ("%d是偶数", x);
	
```

#### 或

在文本之中 该符号为 $\vee$ , 在代码之中该符号写作 $|$

倘若我们要将 $a$ 和 $b$ 作或运算我们这么写

```c++
a | b
```

运算定义： 

​	记 $a_i$ 为 $a$ 在二进制下的第 $i$ 位， $b_i$ 为 $b$ 在二进制下的第 $i$ 位

​	我们有

​	$a \vee b = \sum\limits_{i = 1} (a_i \vee b_i) ·  2^{i - 1}$

​	其中 $a_i$ 与 $b_i$ 均为 bool 变量 

​	对于两个布尔变量 $A$ 和 $B$：
$$
A \vee B = 
\begin{cases} 
1 & \text{如果 } A = 1 \text{ 或 } B = 1 \\[2mm]
0 & \text{否则}
\end{cases}
$$
小例子 ：

​	$4 \vee 3 = 7, 11 \vee 5 = 15, 4\vee 1 = 5$

#### 异或

在文本之中 该符号为 $\oplus$ , 在代码之中该符号写作 ^

倘若我们要将 $a$ 和 $b$ 作异或运算我们这么写

```c++
a ^ b
```

运算定义： 

​	记 $a_i$ 为 $a$ 在二进制下的第 $i$ 位， $b_i$ 为 $b$ 在二进制下的第 $i$ 位

​	我们有

​	$a \oplus b = \sum\limits_{i = 1} (a_i \oplus b_i) ·  2^{i - 1}$

​	其中 $a_i$ 与 $b_i$ 均为 bool 变量 

​	对于两个布尔变量 $A$ 和 $B$：
$$
A \oplus B = 
\begin{cases} 
1 & \text{如果 } A和B之中有且仅有一个1 \\[2mm]
0 & \text{否则}
\end{cases}
$$
小例子 ：

​	$4 \oplus 3 = 7, 11 \oplus 5 = 14, 4\oplus 1 = 5$

##### 关于异或的性质

​	1. 对于 $\forall a \in N$, 我们有 $a \oplus a = 0$

​	这个性质意味着一个 异或方程是可以移项的， 且有着唯一解

​	即倘若 已知 $a_1, a_2, .... a_n$  未知 $a_{n + 1}$

​	并且已知 

​	$a_1 \oplus a_2 \oplus a_3 ... \oplus a_n \oplus a_{n + 1} = a_{0}$

​	我们会有

​	$a_{n + 1}=a_0 \oplus a_1 \oplus a_2 ... \oplus a_{n}$

​	这一性质 是 与运算和或运算所没有的。 

	2. 具有结合律， 交换率
	2.  $0 \oplus a = a$

## Part 2 关于NIM游戏的解法

​	具体 更加本质的理论要用到 Sprague-Grundy 定理， 在本处我们仅对结果进行证明。 

​	假设 我们现在有 $k$ 个堆， 第 $i$ 个堆 有 $a_i$ 个石头， （$a_i$ 可以是 0）

​	我们定义 Nim 和为

​		$Sum = a_1 \oplus a_2 ... \oplus a_k$

​	我们有如下结论 	

​		若在一个人操作之前 ， $Sum = 0$ 则必输 我们称之为 状态一

​		若在一个人操作之前，  $Sum \ne 0$ 则必赢 我们称之为 状态二

​	考虑证明思路

​		（*）对于状态一， 不管我怎么操作一定会转化为状态二

​		（**）对于状态二， 我存在一种操作将其转化为状态一

​	note: 这样的话 一个人 会永远在状态一或状态二 （如果两人足够聪明）

	#### 先证明 (*)

​	我们有 

​		$a_1 \oplus a_2 ... \oplus a_k = 0$

​	假定定理不成立， 也就是说， 我们存在 将 $a_i$ 转化为 $a_i'$

​	我们有

​		$a_1 \oplus a_2 ... \oplus a_i'...\oplus a_k = 0$

​	如果我们将 $a_i, a_i'$ 视为未知数， 会发现我们得到了两个完全相同的异或方程， 不过异或方程有唯一解， 我们得到

​	$a_i = a_i'$ 

​	但是 由游戏规则知  $a_i' < a_i$ 

​	矛盾！ 则 (*) 成立。 

#### 再证明(**)

​	这是一步构造性的证明

​	由于 $Sum \ne 0$ 我们不妨令之为 $s$

​	我们将 $s$ 进行二进制拆解

​	$s=\sum\limits_{i = 1}^{p} s_i 2^{i- 1}$ 

​	其中 $s_i$ 是 $s$ 二进制拆解下的第 $i$ 位， 其中 $p$ 是最高位， 也就是说
​	$2^{p - 1} \le s < 2^p$, 且我们必有  $s_p = 1$ 

​	这意味着什么， 我们至少 可以找到 一个$a_i$ 满足 $a_i$ 的二进制拆分下 第 $p$ 位是 $1$

那么我们令 $a_i$  变为 $a_i' = a_i\oplus s$ 就是我们要的一个解

​	我们 要证明两个点	

​	1. $a_1 \oplus a_2 ... \oplus a_i'...\oplus a_k = 0$

​	2. $a_i' < a_i$

 第一点

​	只要证

​	$a_1 \oplus ... \oplus a_i \oplus s... \oplus a_k = 0$

​	由交换律知

​	$a_i \oplus ... \oplus a_i... \oplus a_k \oplus s = s\oplus s = 0$

​	得证

第二点

​	由于 $a_i$ 二进制下的 第 $p$ 位是 $1$ 那么我们不妨令之最高位  $p'$,  我们会有$p'\ge p$

​	我们记录 $a_i$ 在二进制 表示下第 $k$ 位 是 $x_p$ 

​	$a_i'$ 在二进制表示下第 $k$ 位是 $x'_k$

​	由于 $s$ 的最高位 为 $p$ 也就是说异或结果之后， 对 $a_i$ 中 第 $p + 1$ 到 第 $p'$ 位没有任何影响

​	即 $x'_k = x_k$ , $k \ge p + 1$

​	且 $x_p = 1, x'_p = 0$ 	

​	$a_i'-a_i = \sum\limits_{i = 1} ^ {p'} x_i' 2^{i - 1} - \sum\limits_{i = 1}^{p'}x_i2^{i - 1} = \sum\limits_{i = 1}^{p}x'_i 2 ^{i - 1} - \sum\limits_{i -= 1}^{p}x_i2^{i - 1} \le -2^{p - 1} + \sum\limits_{i = 1}^{p - 1}2^{i - 1} < 0$

​	则第二点得证。
